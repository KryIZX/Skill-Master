# What Makes a Good Whop App

Suggestions from **Steven S, Whop founder**. These are guidelines, not requirements. If the user asks for something that conflicts with them, do what the user asks.

## 1. Empower Creators

Let each creator customize their instance of the app so their whop stands out: custom prompts in AI apps, branding, rules, copy. Put these settings in the dashboard view.

## 2. Drive Discovery

How shareable is the app, and what inside it is worth sharing? Build features that turn each user into a node that attracts more users: shareable results, leaderboards, invites, and forum posts about activity in the app (activity in the feed breeds more engagement). This compounds over time.

## 3. Price Sustainably

Make money without gouging creators or customers. Consider free tiers, fair usage-based pricing, and pricing that scales with the creator's success.

## 4. Keep UX Simple

Can a new user finish the main task in under 30 seconds? Make the core action obvious, minimize clicks, and reveal advanced options only when needed.
