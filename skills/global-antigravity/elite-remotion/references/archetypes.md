# Visual Archetypes for Elite Remotion

Choose an authentic visual archetype before writing a single line of React. Never mix them into a muddy compromise.

---

## Archetype 1: Hyper-Kinetic Swiss Editorial

**Inspiration**: International Typographic Style, Wim Crouwel, Experimental Jetset, Contemporary Swiss Motion Posters.

### Visual Rules:
- **Palette**: Monochromatic core (`#0A0A0A` near-black, `#F5F5F7` stark paper-white) + exactly ONE stark saturated ink color (e.g., Swiss Vermilion `#FF3B30` or International Klein Blue `#002FA7`).
- **Typography**: Ultra-dense grotesque sans-serif (`Neue Haas Grotesk`, `Inter Display`, or `PP Neue Montreal`) set in extreme scales: `120px` to `180px` headlines colliding directly with `14px` monospace captions.
- **Graphic Elements**: Heavy `2px - 4px` solid rules dividing modules, coordinate numbering (`[01.0]`, `INDEX // 04`), running ticker tapes across edges, tight grid bounding boxes.
- **Motion Character**: Staccato snap cuts, letter-by-letter mechanical typing, harsh camera pans with zero blur, modular box expansions.

## Archetype 2: Titanium Hardware / Linear Minimalist

**Inspiration**: Apple Keynotes, Linear.app product reels, Teenage Engineering hardware design.

### Visual Rules:
- **Palette**: Deep milled obsidian (`#08090C`, `#12151C`), titanium borders (`rgba(255, 255, 255, 0.08)` to `rgba(255, 255, 255, 0.16)`), subtle silver reflections.
- **Typography**: Geometric sans with wide tracking (`letterSpacing: -0.03em` for large headers, `0.08em` for small technical labels).
- **Graphic Elements**: Precise chamfered corners, subtle inner specular highlights (`box-shadow: inset 0 1px 0 rgba(255,255,255,0.1)`), real working UI components, live terminal windows with actual syntax highlighting.
- **Motion Character**: Heavy inertial damping, smooth monolithic sliding panels, subtle camera depth of field, refined momentum.

## Archetype 3: Industrial Cyber-Brutalist

**Inspiration**: Military avionics, radar HUDs, declassified blueprints, terminal telemetry.

### Visual Rules:
- **Palette**: Deep tactical charcoal (`#0D0F12`), monochromatic wireframes, highlighted with high-voltage Hazard Amber (`#FFAA00`) or Acid Volt (`#CCFF00`).
- **Typography**: Dense monospaced fonts (`JetBrains Mono`, `Fira Code`, `SF Mono`). Numbers formatted with fixed decimals (`FPS: 60.00`, `LATENCY: 1.42ms`).
- **Graphic Elements**: Crosshair reticles `(+)`, corner brackets `[ ]`, dashed guide rules, real ASCII diagrams, active frame counters.
- **Motion Character**: Digital scan sweeps, binary glitch flickers on transitions, snappy coordinate tracking.

---

## Archetype 4: Swiss Editorial Serif (The Literary-Engineering Clash)

**Inspiration**: Contemporary Swiss design studios (Dinamo, Optimo), luxury monograph book design, European film titles, architectural catalogs.

### Visual Rules:
- **Palette**: Warm obsidian (`#0C0D0E`), Warm bone/parchment (`#F5F2EB`), Antique ivory (`#FAF8F5`), punctuated by deep racing green (`#002B1B`), warm Ochre (`#D97706`), or Swiss red (`#E63946`).
- **Typography**: The intentional clash: High-contrast display serif (`Instrument Serif`, `Bodoni Moda`, `Cormorant Garamond`, `Newsreader`) with sweeping italics set at massive scales (`120px - 180px`), juxtaposed against razor-sharp `12px - 14px` Swiss monospaced coordinates (`JetBrains Mono`, `Space Mono`).
- **Graphic Elements**: 1px crisp dividing rules, catalog accession numbers (`FIG. 04 / CHAPTER II`), delicate corner crosshairs `(+)`, edge ledger tables, archival document stamps.
- **Motion Character**: Elegant vertical masked revelations (sliding out from razor bounding boxes), typographic tracking expansions, gentle continuous breathing drift, and sudden staccato camera punches.
